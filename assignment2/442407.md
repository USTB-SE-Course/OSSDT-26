## 3. 冲突产生与解决

### 3.1 共同基础版本与双方修改

双方修改基于同一个main版本：

https://github.com/mwu381690-debug/git-practice/commit/059cbaf

practice.md原来的学习目标为：

```text
Learning goal: practice Git branches and pull requests.
```

同学将其修改为：

```text
Learning goal: practice teamwork through pull requests.
```

同学提交：

https://github.com/mwu381690-debug/git-practice/commit/3ee9e95

我在main中将同一行修改为：

```text
Learning goal: practice resolving merge conflicts with Git.
```

我的提交：

https://github.com/mwu381690-debug/git-practice/commit/5e6dbfa

### 3.2 真实冲突的产生

我将同学的PR获取为本地分支collaboration/from-jstriker7，切换到该分支后，执行git merge main。

由于两个分支对practice.md中的同一行作出了不同修改，Git无法自动判断应采用哪个版本，产生了内容冲突。终端实际输出为：

```text
Auto-merging practice.md
CONFLICT (content): Merge conflict in practice.md
Automatic merge failed; fix conflicts and then commit the result.
```

冲突由实际Git合并操作产生，没有手动编造冲突标记。

### 3.3 解决步骤与最终结果

我使用记事本编辑practice.md，删除冲突标记，将双方目标整合为：

```text
Learning goal: practice teamwork through pull requests and resolve merge conflicts with Git.
```

这样处理的理由是：同学强调团队协作，我强调冲突解决，两项都是本次练习的目标，可以合并保留。

完成编辑并保存后，我检查文件，执行git diff --check，再暂存并提交解决结果。

- 冲突解决提交：https://github.com/mwu381690-debug/git-practice/commit/bbb03c2

随后，我将本地解决结果推送到原PR的来源分支collaboration/jstriker7，原PR自动更新，无须创建替代PR。检查后，我在GitHub上合并该PR。

- 最终合并PR：https://github.com/mwu381690-debug/git-practice/pull/2
- 最终合并提交：https://github.com/mwu381690-debug/git-practice/commit/1238bff

最后，我切换回本地main并拉取远程更新。git status显示本地与origin/main同步，工作区干净；查看practice.md确认整合后的学习目标已经保留。

