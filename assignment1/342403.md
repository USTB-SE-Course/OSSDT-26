## 1. 项目用途与选择原因

PCL2 是运行在 Windows 上的 Minecraft 启动器，使用 VB.NET 和 WPF 编写，主要面向需要管理游戏版本、Mod 和整合包的玩家。我喜欢玩 Minecraft，也长期使用 PCL。和正版启动器相比，我觉得 PCL 在启动游戏、添加 Mod 和整合包方面方便不少，以前下载游戏资源也很方便；在国内同类启动器里，我认为它算数一数二。

## 2. 开源许可证

仓库根目录的 [LICENCE](https://github.com/Meloong-Git/PCL/blob/main/LICENCE) 包含《PCL 分发有限许可》和附在后面的《PCL 存储库合理使用指南》。GitHub 页面将许可证标记为 `NOASSERTION`。指南明确说明自己不是法律文件；分发许可则单独列出了作者允许的使用条件。它是作者自拟的有限许可，不是 MIT、Apache 等常见标准许可证，因此报告中把 PCL 描述为“源码公开、复用受限制”更准确。

指南将使用分为轻度和重度。少量参考代码，或开发与 PCL 实质功能不重叠的软件，属于轻度使用，需要署名并避免造成关联误认。修改 PCL，或大量参考其内容重新实现启动、下载、Mod 管理等功能，则属于重度使用；指南要求标明第三方二次创作、按规定命名、在关于页面署名并公开源代码。带有 Minecraft 启动功能的衍生软件还需保留正版购买劝导，“PCL Pro”也被列为不允许的名称。

## 3. 维护与活跃情况

README 说明，仓库代码会在每次 PCL 发布时同步，并非实时更新，所以 GitHub 提交记录不能完整反映作者平时的开发过程。发布记录显示，2026 年 7 月和 8 月有 2.13.0.1、2.13.1.0、2.13.1.1；10 月 20 日发布的 2.99.0.0 则说明因相关法律法规，PCL 不再提供 Minecraft 下载功能。

截至 2026-11-22，GitHub 页面显示有 217 个未关闭的 issue、575 个 PR。11 月 20 日合并的 [PR #9567](https://github.com/Meloong-Git/PCL/pull/9567) 修复了自定义 JVM 参数中的 `&` 被转义成 `&amp;` 的问题；[PR #9577](https://github.com/Meloong-Git/PCL/pull/9577) 更新了杂志主页作者名。11 月 21 日又有人提交了 [issue #9589](https://github.com/Meloong-Git/PCL/issues/9589)。这些记录分别能看到版本调整、代码修复和社区反馈。
