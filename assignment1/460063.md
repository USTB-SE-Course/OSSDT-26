## 1. 项目用途与选择原因

Requests 是一个面向 Python 的 HTTP 客户端库，主要用于让程序向网站或 Web API 发送 HTTP/1.1 请求，并读取服务器返回的状态码、响应头和内容。与直接使用较底层的网络接口相比，Requests 提供了更简洁的调用方式，可以处理 GET、POST 等常见请求，也支持查询参数、JSON 数据、表单和文件上传。项目还提供了 Session 与 Cookie 持久化、Basic/Digest 身份验证、TLS/SSL 证书验证、代理、超时设置和流式下载等功能。因此，它适用于需要访问网络服务的 Python 开发者，例如后端开发、API 调用、自动化脚本和数据获取等场景。

我选择该项目有三个原因。第一，Requests 的用途直观，能够帮助我了解 Python 程序如何与网络服务交互。第二，项目文档、源代码、测试和许可证文件都公开在 GitHub 上，适合通过仓库结构了解开源项目。第三，该项目有版本发布、问题反馈和代码审查记录，可以观察真实项目的维护过程。
