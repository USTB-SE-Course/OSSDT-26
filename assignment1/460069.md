## 1. 项目用途与选择原因

Vue.js 是一个开源的 JavaScript 前端框架，主要用于构建网页用户界面和 Web 应用程序。它提供了响应式数据、组件化开发、事件处理和数据绑定等功能，可以帮助开发者减少重复代码，提高开发效率。

例如，当页面中的数据发生变化时，Vue 可以自动更新相关的页面内容，不需要开发者手动操作 DOM。同时，开发者可以将复杂的页面拆分成多个组件，使代码更容易理解和维护。

Vue.js 的主要用户包括前端开发人员、全栈开发人员以及正在学习 Web 开发的学生。

我选择这个项目，是因为我在之前的课程实践中使用过 Vue 3 和 Element Plus 开发前端页面，并通过 Axios 与后端进行数据交互。通过这次调研，我希望进一步了解自己使用过的框架，也想了解开源软件是如何维护和持续发展的。

## 2. 开源许可证

Vue.js 使用 MIT License（MIT 许可证）。

许可证文件：
https://github.com/vuejs/core/blob/main/LICENSE

MIT 许可证是一种比较宽松的开源许可证，允许用户使用、复制、修改和分发软件，也允许将软件用于商业项目。

但是，在复制或再分发软件及其主要部分时，需要保留原有的版权声明和许可证声明。使用者不能因为修改了部分代码，就忽略原项目的版权信息。

我认为这种许可证有利于开发者学习和使用开源软件，也能促进软件技术的传播。
