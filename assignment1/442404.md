## 1. 项目用途与选择原因

Code - OSS 是 Visual Studio Code 的开源源码项目。它把代码编辑、项目搜索、调试和版本控制集中在一个工作区，适合编程初学者、个人开发者和开发团队。打开一个项目文件夹后，用户可以在文件列表中查看目录结构，在编辑器中修改代码，并在集成终端执行项目命令。遇到分散在多个文件中的代码时，可以先用全局搜索找到变量或函数的引用，再跳转到定义查看具体实现。调试时可以设置断点，观察程序暂停时的变量值和调用位置。

我选择这个项目，是因为代码编辑器和课程里的编程任务联系紧密。读懂一个陌生项目，通常要在文件之间来回查找。定位程序出错的位置，又需要从代码阅读切换到实际运行。把这些操作放在同一个工作区里，可以减少反复打开文件和切换工具的时间。我也想了解它怎样适应不同语言的开发需求。项目的扩展机制提供了一个切入点，用户可以按任务安装语言支持、格式化或调试扩展，配置自己的工作环境。[项目仓库与 README](https://github.com/microsoft/vscode)

## 2. 开源许可证

Code - OSS 仓库的 `LICENSE.txt` 采用 MIT 许可证。该许可证允许使用、复制、修改和分发其覆盖的源码。分发软件的全部或实质性部分时，需要保留原版权声明和许可声明。例如，如果把仓库中一段实质性代码整合到另一个项目并公开发布，就应在分发材料中保留相应声明，让接收者能够查明代码来源和使用条件。微软发布的 Visual Studio Code 产品适用另外的产品许可条款，仓库 README 对源码和产品的许可分别作了说明。[MIT 许可证文件](https://github.com/microsoft/vscode/blob/main/LICENSE.txt) · [仓库许可说明](https://github.com/microsoft/vscode#license)

参与项目可以从反馈问题开始。在 GitHub Issues 中搜索关键词，可以先了解其他用户是否遇到过同样的问题。提交问题时，可以写明使用的版本和系统，列出复现步骤，并说明预期结果和实际结果。想贡献代码时，可以按官方指南配置开发环境、运行测试，再通过 PR 说明改动内容。[官方贡献指南](https://github.com/microsoft/vscode/wiki/How-to-Contribute)
