## 1. 项目用途与选择原因

Vue.js 是一个渐进式、可逐步采用的 JavaScript 框架，用于构建 Web 用户界面。`vuejs/core` 是 Vue 3 的核心实现，主要用 TypeScript 编写，包含响应式系统、虚拟 DOM、编译器和运行时等模块（官网：<https://vuejs.org/>）。它面向前端开发者：既可以在已有页面上引入一小部分 Vue 增强交互，也可以用它开发完整的单页应用；要解决的是"如何把界面拆成可复用组件，并在数据变化时自动更新 DOM"。

选择它有三个原因。第一，我在学习中接触过 Vue，能读懂基本用法和目录结构，不至于只停留在名字层面。第二，它是 MIT 许可证，条款短、义务明确，适合练习阅读 LICENSE 文件。第三，仓库维护很活跃，commit、release、issue 和 PR 都容易查到，便于用真实证据完成调研，而不是凭印象判断。

## 2. 开源许可证

许可证名称：MIT License；SPDX 标识：MIT。许可证文件：<https://github.com/vuejs/core/blob/main/LICENSE>

MIT 属于宽松型许可证，允许使用、复制、修改、合并、发布、分发乃至出售软件副本，前提是保留版权声明和许可声明。需要注意的一项义务是：许可证原文写明"The above copyright notice and this permission notice shall be included in all copies or substantial portions of the Software."，即**在软件副本或实质部分中必须保留版权声明与本许可声明**。也就是说，若把 Vue 源码或较大的代码片段用于自己的项目并再分发，不能删掉 LICENSE 中的版权行，否则不满足授权条件。许可证还声明软件按"原样"提供、不作担保，这是使用时需知晓的风险边界。
