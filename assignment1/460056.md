## 1. 项目用途与选择原因

Requests 是一个基于 Python 的开源 HTTP 客户端库，主要用于发送 HTTP/1.1 请求。它可以帮助开发者方便地发送 GET、POST、PUT 和 DELETE 等请求，并处理服务器返回的数据。

该项目主要面向 Python 开发者，适用于 Web 开发、网络编程和 API 数据交互等场景。与直接使用较底层的方法相比，Requests 提供了更加简单、易读的接口，降低了 HTTP 请求的开发难度。

我选择 Requests 项目，是因为 Python 是计算机专业学习中常用的编程语言，而 HTTP 通信也是计算机网络和 Web 开发的重要基础。通过调研这个项目，我希望进一步了解 Python 开源软件的设计、许可证以及社区协作方式。

## 2. 开源许可证

Requests 项目采用 Apache License 2.0 开源许可证。

根据该许可证的第4条（Redistribution），用户可以复制、修改和重新发布该软件，但需要遵守一定的条件。例如，重新分发软件时必须附带许可证副本；如果修改了文件，需要明确标注修改内容；同时，还需要保留原始代码中的版权、专利、商标和归属声明。

此外，如果原项目包含 NOTICE 文件，重新分发时还需要按照许可证要求保留其中相关的声明信息。

Apache License 2.0 允许用户使用、修改和分发软件，也允许用户对自己的修改添加版权声明，但必须遵守许可证规定的条件。
