## 1. 项目用途与选择原因

mini-coding-agent 是一个使用 Python 编写的精简编程智能体项目。它通过相对易读的实现，展示 AI 编程助手如何将大语言模型与工作区信息、工具调用等组件结合起来。项目主要面向希望了解 Coding Agent 工作原理的学习者和开发者，而不仅仅是把它当作一个日常编程工具使用。

根据项目 README，智能体在处理任务时，可以读取工作区相关信息，与模型交互，并使用工具执行操作；项目还涉及对话状态管理和需要审批的操作等内容。这让我看到，一个 Agent 除了生成文字，还需要考虑如何与外部环境交互以及如何控制操作风险。

我选择这个项目，是因为我对 AI 算法和 Agent 开发感兴趣，希望了解编程智能体的基本工作流程。相比直接阅读大型框架，先观察一个强调精简和可读性的项目，更有助于我建立对模型、工具和工作区之间关系的初步认识。
