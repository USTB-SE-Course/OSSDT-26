## 1. 项目用途与选择原因

smolagents 是一个用 Python 编写的大语言模型智能体库。它把模型、工具和多步执行流程组织在一起，让开发者可以在程序中把搜索、计算等操作交给工具，并让模型根据工具返回的结果决定下一步。例如，整理某个主题的资料时，智能体可以先搜索，再根据已有结果补查缺失的信息，最后汇总。项目提供 `CodeAgent` 和 `ToolCallingAgent` 两种实现，前者让模型用 Python 代码表达动作，后者通过结构化调用选择工具并传入参数。[项目 README](https://github.com/huggingface/smolagents#readme)

它主要面向正在学习智能体工作原理的 Python 开发者，以及需要为科研或应用搭建工具调用原型的人。选择这个项目，是因为同一个仓库就能看到模型接口、工具和执行流程如何配合，便于比较两种调用方式。按代码组织看，核心实现集中在 `src/smolagents/`，仓库也有单独的文档、示例和测试，适合作为一个中等规模的调研对象。[仓库目录](https://github.com/huggingface/smolagents)
