## 1. 项目用途与选择原因

Requests 是一个 Python HTTP 客户端库，主要用于在程序中向网站或网络接口发送请求，并处理服务器返回的数据。它提供 GET、POST 等常见请求方式，支持请求参数、JSON 数据、身份认证、Cookie 和超时设置等功能。开发者可以利用它调用接口、获取公开数据，或者编写自动化脚本。

它面向需要进行网络通信的 Python 开发者，也适合正在学习接口调用的学生。例如，程序可以通过 Requests 请求一个返回 JSON 数据的接口，再提取其中的信息进行后续处理。

选择这个项目，是因为它的用途明确，能够与计算机网络课程中的 HTTP 请求和响应联系起来，也与本课程的 Python 开发方向相关。项目同时提供代码、文档、许可证和维护记录，便于观察开源软件如何组织和维护。
